# yldrmzffr/homebrew-tap

Homebrew casks for [humon](https://github.com/yldrmzffr/humon), a small, fast MongoDB client.

```sh
brew install --cask yldrmzffr/tap/humon
```

`Casks/humon.rb` is updated automatically by humon's release workflow; please
open issues in the [humon repo](https://github.com/yldrmzffr/humon/issues).
